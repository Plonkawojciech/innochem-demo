# INNOCHEM — miesięczny raport utrzymania i SEO

Szablon do wykorzystania po rzeczywistym uruchomieniu innochem.pl. Nie jest raportem osiągniętych wyników. Pierwszy okres i wykonawcę zgodnego z aktualną umową wpisujemy przy odbiorze; nie liczmy 12 miesięcy od startu prywatnego podglądu.

Okres: do uzupełnienia. Data uruchomienia: do uzupełnienia po odbiorze. Źródła: Search Console klientki, GA4 klientki (tylko zakres po zgodzie), dane finansowe sklepu i raporty utrzymania. Brak dostępu oznacz jako brak danych, nie zero.

| Obszar | Wynik za okres | Porównanie i dowód |
| --- | --- | --- |
| Search Console: kliknięcia / wyświetlenia / CTR / średnia pozycja | Uzupełnić z eksportu i podać filtr domeny/kraju/okres | Poprzedni równy okres; przy pierwszym raporcie jest to punkt odniesienia |
| Najważniejsze uzgodnione frazy i strony docelowe | Fraza, strona, wynik | GSC; nie przedstawiać średniej pozycji jako gwarantowanego miejsca każdego użytkownika |
| Indeksacja i błędy | URL wymagające działania, status sitemap/robots/canonical | Eksport GSC + kontrola rzeczywistej strony; wysłanie sitemap nie jest potwierdzeniem indeksacji |
| GA4: wejścia → produkty → koszyk → checkout → opłacone zakupy | Uzupełnić po walidacji i odbiorze zdarzeń | Pomiar po zgodzie, wyłączenie testów; zakup tylko po potwierdzeniu płatności |
| Zamówienia i sprzedaż | Dane z bazy sklepu, oddzielnie opłacone / COD / anulowane / refundacje | Źródło finansowe jest w sklepie; GA4 nie obejmuje każdego klienta i money-only korekt |
| Wykonane prace SEO | Konkretne URL i zmiany, tytuły/opisy/schema/przekierowania | Data, commit lub publikacja, sprawdzenie końcowego URL |
| Artykuł poradnikowy | Uzgodniona fraza, temat, link i data publikacji | Jeden miesięcznie ok. 800–1200 słów zgodnie z umową; zatwierdzenie treści i brak niepotwierdzonych norm oleju |
| Hosting i bezpieczeństwo | Dostępność, zgłoszenia/incydenty, aktualizacje i wynik kontroli | Raport monitora i wykonane działania; nie ukrywać przerw w podglądzie |
| Kopie i odzyskanie | Daty kopii, lokalizacja poza VM, ostatni rzeczywisty restore | Manifesty/sumy i wynik; sama obecność pliku nie potwierdza odtworzenia |
| Obsługa i drobne zmiany | Czynności, czas, pozostały limit | Do 5 godzin miesięcznie zgodnie z umową; dodatkowy zakres uzgodnić przed rozliczeniem |

Po tabeli wpisz krótko: co poprawiono, jakie konkretnie problemy wymagają decyzji właścicielki i następne prace z terminem. Nie obiecuj pozycji ani sprzedaży. Nie uruchamiaj Ads, budżetów lub subskrypcji na podstawie tego raportu.

Raport dla klientki jest szkicem do osobno autoryzowanej wysyłki. Surowe eksporty z danymi klientów i sekrety pozostają poza publicznymi materiałami. W utrzymaniu wskaż właściciela alarmów, kanał zgłoszeń i terminy miesięcznego raportu/artykułu; dostarczenie alarmu wymaga rzeczywistej próby.
